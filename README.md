# Tetris project

このリポジトリはブラウザで遊べるテトリス風ゲームです。`index.html` をブラウザで開くだけでプレイできます。

## 遊び方

- **← / →**: 左右に移動
- **↓**: ソフトドロップ
- **↑**: 右回転
- **Z**: 左回転
- **スペース**: ハードドロップ
- **C**: ホールド

10 ライン消すごとにレベルが上がり、落下速度が上昇します。ブロックが天井に到達するとゲームオーバーです。

## 開発メモ

ゲームロジックは `main.js` に実装されており、HTML キャンバスを利用して描画しています。スタイルは `style.css` で調整しています。
